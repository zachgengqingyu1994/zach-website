🔥 LATEST / 最新随笔 2026.05.18

别太神化大模型：聊聊普通打工人怎么用好 AI 工具找工作。

大家都说 AI 抢饭碗，每天看着各种"即将颠覆一切"的新闻，我自己也会焦虑。但真到了找工作、写代码的实操阶段，我的切身体会反而是需要祛魅……

坦白讲，这几年看多了宏大叙事，作为普通人很难不慌。但钻进业务里写代码时，我发现目前的大模型其实更像是一个不知疲倦、但有时会犯错的实习生。在面试前，我建议大家踏踏实实地用 Cursor 跑几遍自己的项目代码，让它帮你找出潜在的 bug，或者优化一下注释。别在简历里吹嘘自己"精通各种 Prompt 魔法"，现在没人信这个了。

面试官更想看到的是，你作为一个踏实干活的人，怎么借用工具把一个细小的业务逻辑做得更稳健。对技术保持敬畏，但不要被它吓破胆。当个务实的"拼图者"，用好现成的 API 去解决实际痛点，这种脚踏实地的能力，往往比张口闭口就是"底层重构"更让人安心。

📝 REFLECTION / 求职反思 2026.05.16

从大厂出来后的一点感触：扒掉平台光环，我还剩下什么？

最近和几个刚毕业以及刚离开大厂的朋友聊天，发现大家都有很深的"职级焦虑"。好像没有那个 Title，自己就不值钱了……

以前我也觉得，进大厂就是上岸，有个好职级就能证明自己的能力。但这波行业的冷水浇下来，真的让我清醒了。扒掉大厂的平台、完善的基建和细致的分工，我们个人的技术栈其实是很脆弱的。

如果你现在正在看机会，Zach 的一点拙见是：不要只盯着 Title 和规模看。去看看那些虽然人不多，但业务能跑通商业闭环的小团队。去那里做一个能独立扛事儿的"全干工程师"，哪怕只是写一写普通的增删改查，哪怕天天跟客户磨皮。只要能帮团队活下去，这种从 0 到 1 解决生存问题的能力，比你懂多少个高级架构设计模式都实在得多。认清自己是个普通人，反而是一种巨大的解脱。

💡 RESUME / 简历心得 2026.05.15

你的简历，真的需要写那么多"精通"吗？

帮几位同行朋友看了看简历，发现大家为了增加过筛率，很容易把自己包装成无所不能的"全栈大神"……

说句掏心窝子的话，每次看到简历上写着"精通大模型底层原理、精通八大语言"，我都会替候选人捏把汗。真正的面试场上没有那么多神仙打架，面试官大部分也是普通打工人，他们拿着这份简历，心里只是想找个能干活、好沟通的队友。

我现在的建议是：简历尽量写得"老实"一点。把你真正踩过坑、加过班熬过夜解决的那个小 bug 写清楚；哪怕只是优化了一个几百毫秒的数据库查询，或者用脚本帮运营同事节省了半小时工作量，也比堆砌一堆你没怎么摸过的 AI 概念要强得多。找工作就像交朋友，少一点套路，真诚永远是成本最低、也是最有效的敲门砖。

🗣️ INTERVIEW / 面试实录 2026.05.14

关于八股文：承认自己的笨拙，也是一种底气。

算法岗卷上天，开发岗面试一上来也是各种底层原理。背不出八股文，难道就找不到工作了吗？

作为一个记性不太好的人，我以前非常抗拒背八股文。面试时如果卡壳，就会觉得很丢脸，为此没少受挫。后来我慢慢想通了，人的脑容量有限，既然背不过，不如坦诚一点。

现在如果有人问我太偏的底层概念，我会直接说："这个源码细节我确实记不清了，但我知道业务中遇到这种报错去哪查文档，如果遇到性能瓶颈我会怎么打日志验证。"结果发现，很多面试官反而能接受这种踏实的态度。技术世界这么大，承认自己的无知不丢人。能带着这份笨拙，一直保持耐心去解决具体的 bug，才是咱们普通开发者的生存之道。

🔮 INDUSTRY / 行业观察 2026.05.13

AI 行业的真实面貌：我们大多数人，都在做"数据搬运工"

媒体上的 AI 行业总是充满科幻感，仿佛大家每天都在探讨硅基生命。但一线从业者的日常，其实非常朴实且枯燥……

不要被新闻里动辄千亿参数的大模型吓到，觉得 AI 行业的门槛高不可攀。其实钻进很多 AI 公司去看，最缺人、日常工作量最大的，反而是做数据清洗、对齐和工程封装的"搬运工"。

做数据很苦，要对着一堆乱码人工微调，没什么光环可言。写业务逻辑也枯燥，每天都在处理 API 超时和报错。但如果你能静下心来，把一堆脏数据洗成干净的格式，把一个容易崩溃的接口封装得极其稳定，那你在这个行业里就永远有饭吃。Zach 觉得，咱们都是在数字世界里修修补补的蓝领工人，一砖一瓦地把活干漂亮，心里才觉得踏实。

💼 PRODUCT / 业务视角 2026.05.11

给同行的一点建议：少讲点概念，多敬畏下业务。

都在说要做"懂模型的跨界人才"，但我越来越觉得，懂人、懂真实的业务场景，比懂模型参数重要得多……

刚接触大模型的时候，我也偶尔会飘，喜欢把"涌现"、"思维链"挂在嘴边，显得自己很懂行。但被现实毒打几次后发现，真正的客户或者业务方，根本不关心你用的是哪家的底层模型，他们只关心这东西能不能帮他们减少出错率，能不能让他们早下班半小时。

做产品或者写代码，越往后越需要谦卑。放下那些高深的大词，去一线看看同事是怎么笨拙地操作 Excel 的，怎么在微信群里复制粘贴的。然后用技术悄无声息地帮他们把这些杂活干了。最好的技术服务，是不让用户感觉到技术的门槛。能弯下腰去解决土味痛点的人，求职时往往最抢手。

🧘 MINDSET / 心理建设 2026.05.10

找工作期间的焦虑：允许自己停下来，喘口气。

投出几十封简历石沉大海，看着群里别人都在晒 Offer，心态崩了怎么办？聊聊这段时间的一点心理建设。

过去这阵子，我也经历过投简历没人理、面试发挥失常后的深夜自我怀疑。这种被市场反复拒绝的滋味真的很折磨人。我想跟同样在看机会的朋友说：在这个行业的调整期，找不到工作大概率不是你不够努力，只是齿轮刚好没有卡上而已。

允许自己沮丧，允许自己白天合上电脑去逛个公园，或者痛痛快快地打一天游戏。千万别把自己的全部人生价值都绑定在一个 Offer 上。找工作就像跑一场不知终点的马拉松，保持健康的作息、按时吃饭睡觉，比每天焦虑地在招聘软件上刷个不停重要得多。照顾好自己，才是长久之计。

🌱 CAREER / 职业规划 2026.05.09

30岁的程序员：不用硬挤管理岗，做个靠谱的老兵也挺好。

好像行业里总有一种声音，告诉你过了三十岁"不升管理就淘汰"。但我慢慢发现，其实还有另一条路……

以前我也觉得，到了年纪必须得带团队、搞晋升，不然就是混吃等死。但随着精力和重心的变化，我发现自己可能真的不擅长、也不喜欢处理那些复杂的人际关系和向上汇报。

后来想通了，安心做个能写代码的资深老兵，反而如释重负。每天帮年轻同事排排雷，写几段自己觉得结实的代码，然后尽量按时下班陪陪家人。在互联网的洪流里，不是每个人都要做浪潮之巅的弄潮儿。做一块稳固的垫脚石，给团队提供稳定的产出和情绪价值，同样是一件很体面、也很值得骄傲的事。

🔄 COMMUNITY / 开源社区 2026.05.08

参与开源不是为了刷简历，而是为了找个乐子和同频的人。

经常有学弟学妹问我，怎么在 GitHub 上提 PR 才能让简历看起来更牛。我总是有点不知道怎么回答……

现在有一种风气，教人怎么通过提一些改错别字的 PR 来"美化"简历。我觉得这把开源搞得太功利、太累了。我个人的体会是，写代码最快乐的瞬间，其实和找工作无关。

那是在深夜，你偶然帮某个素未谋面的异国开发者修了一个冷门的 bug，或者随手写的一个小工具被人点了个 Star。在这个有些内卷、充满 KPI 的行业里，开源社区更像是一个不问出身的避风港。带着点纯粹的兴趣去分享一行代码，你会收获很多意想不到的善意和乐趣。找工作已经够苦了，留一点纯粹的热爱给自己吧。

🎯 EMPATHY / 换位思考 2026.05.06

作为面试官的一点私心：相比于聪明，我更看重你的"韧性"。

偶尔在公司也会客串一下面试官。在形形色色的候选人里，我发现自己越来越偏爱一种特定的特质……

坐在面试桌对面，我看过很多学历背景耀眼、新技术名词倒背如流的聪明人。但说句实话，我自己私心最愿意给过、最想共事的，往往是那些看起来有些笨拙，技术也许不是最拔尖，但在讲到自己是怎么苦熬三天排查一个线上内存泄漏问题时，眼里有光的人。

日常开发大部分时间是在打"逆风局"，顺风局谁都会写业务，但出了诡异的 Bug 时，拼的就是谁坐得住、谁有韧性。如果你在面试时，能自然流露出那种"这问题挺难搞，但我愿意死磕到底"的踏实劲儿，相信很多像我一样的普通面试官，都会愿意向你伸出手的。

🤖 PRACTICE / 实践心得 2026.05.05

聊聊大家都在追的 Agent：少想点颠覆，多做点小玩具。

Agent 概念火了，群里各种"取代人类"的争论满天飞。作为一个在一线敲键盘的，我反而觉得有点心虚……

最近听了太多关于"多智能体协同将颠覆公司架构"的讲座。但我自己业余时间写代码调用模型时发现，目前的稳定性还远远撑不起那么宏大的叙事，经常一不小心就陷入死循环。

对于咱们普通开发者找工作，我的建议是：别去想怎么造个能聊天的变形金刚，不如踏踏实实地用 API 写一个小脚本，帮自己把每天整理日报的十分钟省下来，或者帮运营同事做个能自动提炼邮件摘要的小插件。少谈点颠覆时代的口号，多做点能立刻产生幸福感的微小工具。面试时拿这种自己写的小玩具出来聊，比空谈概念讨喜得多。

💰 CHOICE / 薪资取舍 2026.05.04

面对降薪 Offer：算一算心里的那个"隐形账本"。

大环境降温，很多朋友好不容易拿到 Offer，却发现比上一份工作薪资还低，陷入了深深的纠结和自我怀疑。

谈钱不伤感情。遇到降薪，心里肯定不平衡，我自己换工作时也难受过。但后来我学着给自己建一个"隐形账本"：这份新工作是不是能让我准时下班去接小孩？团队的代码规范是不是健康、不用每天帮别人擦屁股？老板是不是个讲道理的人？

有时候，表面工资数字的下降，换来的是周末不用待命的踏实，以及身心健康的提升。在这个求稳的阶段，平平安安地熬过冬天，就是一种胜利。找工作要量力而行，不和社交平台上的"幸存者偏差"比数字，自己过得舒坦最重要。

🤝 NETWORK / 人脉观念 2026.05.03

找工作时的"弱连接"：脸皮厚一点，别不好意思麻烦别人。

很多内向的程序员，宁愿每天在招聘软件上盲投到深夜，也不好意思发个朋友圈问问有没有内推机会……

我也曾是个极度社恐的人，总觉得找前同事内推是欠了天大的人情。后来发现，在如今这海量简历的市场里，一个靠谱的内部推荐，能帮你跳过机器筛选，省去巨大的精力消耗。

其实只要你平时做人踏实、写代码不挖坑，大家是很乐意顺手帮你递个简历的（毕竟很多公司内推还有奖金）。放下不必要的骄傲和社恐包袱，真诚地向周围的朋友、前同事求助，大方地推销自己的能力。学会求助，本身也是职场成熟的标志之一。

🌧️ SURVIVAL / 面对裁员 2026.05.02

面对裁员潮：这不是你的错，只是一场天气变化。

最近行业里调整很多，身边有不少平时踏实肯干的老黄牛同事也被波及，大家心里都很唏嘘。

有个关系很好的同事办理离职那天跟我说，觉得自己很失败，肯定是哪里没做好才被优化。我当时特别想告诉他：在这个时代，企业裁员往往跟个人的努力与否毫无关系。它更像是遇到了一场突如其来的暴雨，而你的业务线刚好没发雨伞而已。

千万不要用公司的商业决策来惩罚自己的自尊心。收拾好东西，回去好好吃顿饭，睡一觉。天晴了，带着我们平时攒下的手艺和经验，换个地方接着敲代码就是了。作为打工人，我们最大的底气，永远是我们手里这门吃饭的手艺。

🌸 PHILOSOPHY / 年度寄语 2026.05.01

写在 2026：做一个"悲观的乐观主义者"。

面对不确定的市场环境和日新月异的技术，我们普通人该用什么样的姿态去应对未来的工作生活？

现在的环境，谁也不敢拍胸脯说未来一年会怎样。我身边的朋友，有的转行考公了，有的还在死磕技术。我自己现在的状态，大概算是一个"悲观的乐观主义者"。

悲观在于，我承认大环境没以前好了，不再幻想一夜暴富或者轻松拿到几倍涨薪；乐观在于，我相信哪怕技术再怎么变迁，那些真诚、靠谱、愿意脚踏实地帮团队解决问题的人，永远会有他的一席之地。少看点宏观新闻，多关心下自己的饭碗。每天写好当下的这行代码，陪好身边的人。路还长，咱们慢慢走，总能找到一份踏实的回响。
