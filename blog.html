🔥 LATEST / 最新随笔 2026.05.18

作为猎头的一点私心：别太神化大模型，也别被 AI 焦虑压垮。

每天和形形色色的候选人打电话，我听到最多的词就是"焦虑"。大家都怕被 AI 淘汰，拼命在简历里往大模型上靠。但站在招人的那一端，真实情况是什么样的？

坦白讲，这几年看多了宏大叙事，连我这个做猎头的都难免心慌。但在帮各种 AI 独角兽和传统大厂推人的时候，我发现用人部门其实非常务实。他们拿到一份写满"精通各种 Prompt 魔法、颠覆式创新"的简历，心里往往是打鼓的。

相比于空谈概念，面试官更想听到的是：你作为一个踏实干活的人，怎么借用 Cursor 或者现成的 API，把一个细小的业务逻辑做得更稳健。对技术保持敬畏，但不要被它吓破胆。我经常劝候选人，当个务实的"拼图者"，用脚踏实地的能力去解决实际痛点，往往比张口闭口就是"底层重构"更让雇主安心。

📝 REFLECTION / 求职反思 2026.05.16

扒掉大厂光环后，我们在人才市场上到底还剩什么？

这几个月聊了不少刚从大厂离开的朋友，很多人都有很深的"职级失落症"。仿佛没有了那个 Title 和职级，自己就不值钱了……

以前大家觉得，进大厂有个好职级，就是能力的绝对证明。但这波行业的冷水浇下来，连我这个做十年猎头的老兵都清醒了。扒掉大厂完善的基建和细致的分工，很多候选人的个人技术栈其实是很单薄的，离开了平台连个完整的项目都跑不起来。

如果你现在正在看机会，Zach 掏心窝子说一句：不要只盯着大厂的 Title 看了。多去看看那些人不多，但业务能跑通商业闭环的务实团队。去那里做一个能独立扛事儿的"全干工程师"，哪怕只是写普通的增删改查、天天跟客户磨皮。只要能帮团队活下去，这种从 0 到 1 解决生存问题的能力，比你背诵多少个高级架构设计模式都实在。认清自己是个普通人，反而是在这个周期里最大的解脱。

💡 RESUME / 简历心得 2026.05.15

我每周看上千份简历，求求大家别再写那么多"精通"了。

每天帮候选人改简历，发现大家为了增加过筛率，很容易把自己包装成无所不能的"全栈大神"……

说句实话，每次看到简历上写着"精通大模型底层原理、精通八大语言"，我都会替候选人捏把汗。真正的面试场上没有那么多神仙打架，面试官大部分也是每天加班的普通技术人。他们看简历，其实只是想找个能干活、好沟通、不埋坑的队友。

我现在的建议是：简历尽量写得"老实"一点。把你真正踩过坑、加过班熬过夜解决的那个小 bug 写清楚；哪怕只是优化了一个几百毫秒的数据库查询，或者用脚本帮运营同事节省了半小时工作量，也比堆砌一堆你没怎么摸过的 AI 概念要强得多。找工作本质上是找同路人，少一点套路，真诚永远是成本最低、也最有效的敲门砖。

🗣️ INTERVIEW / 面试实录 2026.05.14

关于面试八股文：我从技术总监那里听到的大实话。

经常有候选人跟我吐槽，说现在算法和开发岗面试太卷了，各种偏门底层原理。背不出八股文，是不是就没戏了？

很多候选人如果面试时八股文卡壳，就会觉得很丢脸，甚至影响后续心态。其实我私下跟很多大厂的技术 Leader 交流过，他们也知道人的脑容量有限，很多机械记忆的东西在实战里完全可以查文档。

他们更看重的，是你的"坦诚"和"排错思路"。如果遇到太偏的底层概念，我通常建议候选人直接说："这个源码细节我确实记不清了，但我知道业务中遇到这种报错去哪查文档，遇到性能瓶颈我会怎么打日志验证。"结果发现，大部分面试官反而能接受这种踏实的态度。承认自己的知识盲区不丢人，能带着这份坦诚，一直保持耐心去解决具体的 bug，才是最加分的生存之道。

🔮 INDUSTRY / 行业观察 2026.05.13

真实的一线观察：AI 行业里，大部分人其实都在做"蓝领"。

媒体上的 AI 行业总是充满科幻感，仿佛大家每天都在探讨硅基生命。但作为给这些公司招人的猎头，我看到的是另一幅图景……

不要被新闻里动辄千亿参数的大模型吓到，觉得 AI 行业的门槛高不可攀。其实我帮很多顶尖 AI 公司寻访时发现，他们日常最缺人、工作量最大的，反而是做数据清洗、业务对齐和工程封装的"脏活累活"。

这些工作很苦，要对着一堆乱码微调，处理每天都会崩溃的 API，没什么光环可言。但如果你能静下心来，把一堆脏数据洗成干净的格式，把一个破破烂烂的接口封装得极其稳定，那你在这个行业里永远有饭吃。Zach 觉得，其实咱们都是在数字世界里修修补补的打工人，别想那么多颠覆世界，一砖一瓦地把活干漂亮，心里才觉得踏实。

💼 PRODUCT / 业务视角 2026.05.11

我给候选人的建议：少讲点概念，多敬畏下业务。

都在说要做"懂 AI 的跨界人才"，但我从企业端得到的反馈是：懂人、懂真实的业务场景，比懂几个新名词重要得多……

有时候给用人部门推简历，候选人背景很光鲜，满嘴都是"涌现"、"思维链"这些大词。但往往聊不到两轮就被刷了。为什么？因为真正的业务负责人，根本不关心你背了多少参数，他们只关心这东西能不能帮团队减少出错率，能不能让客户早点签单。

无论是做产品还是做开发，越往后越需要谦卑。放下那些高深的大词，去一线看看同事是怎么笨拙地操作系统的，看看客户的痛点到底多土味。然后用技术悄无声息地帮他们把这些杂活干了。最好的技术服务，是不让别人感觉到技术的门槛。能弯下腰去解决这些实在痛点的人，在我这里永远是最抢手的。

🧘 MINDSET / 心理建设 2026.05.10

接起那个痛哭的电话：允许自己停下来，喘口气。

昨天晚上接到一个候选人的电话，因为连续挂了几个终面，他在电话那头崩溃了。聊聊这段时间的一点心理建设。

过去这阵子，我陪很多优秀的候选人经历了投简历石沉大海、面试发挥失常后的深夜自我怀疑。这种被市场反复拒绝的滋味真的很折磨人。作为陪伴者，我想跟所有正在看机会的朋友说：在这个行业的调整期，找不到工作大概率不是你不够努力，只是供需的齿轮刚好没有卡上而已。

允许自己沮丧，允许自己白天合上电脑去逛个公园，或者痛痛快快地睡一觉。千万别把自己的全部人生价值都绑定在一个 Offer 上。找工作就像跑一场不知终点的马拉松，保持健康的作息、按时吃饭，比每天焦虑地盯着招聘软件重要得多。照顾好自己，才是长久之计。

🌱 CAREER / 职业规划 2026.05.09

30+ 的求职困境：不用硬挤管理岗，做个靠谱的老兵也挺好。

好像行业里总有一种声音，告诉你过了三十岁"不升管理就淘汰"。但我每天都在帮企业招人，其实看到了另一条路……

很多 30+ 的候选人找我聊的时候，都觉得如果简历上没带过团队，就觉得拿不出手。其实大可不必。很多企业的中层管理岗现在反而精简了，他们恰恰缺那种不搞人际关系、不搞向上汇报，就能踏踏实实把核心代码写好的资深一线老兵。

并不是每个人都要做浪潮之巅的弄潮儿，或者天天在会议室里 PPT 撕逼。如果你真的喜欢做技术，安心做个技术基石，每天帮年轻同事排排雷，提供稳定的产出，然后尽量按时下班陪陪家人，这也是一件很体面、很值得骄傲的事。找准自己的定位，比盲目迎合世俗的"管理梦"舒服得多。

🔄 COMMUNITY / 技术热爱 2026.05.08

简历上的 GitHub 链接：别为了给猎头看而去做开源。

经常有候选人问我，怎么在 GitHub 上提 PR 才能让简历看起来更牛，更容易过你们猎头这一关。我总是有点无奈……

现在有一种风气，教人怎么通过提一些改错别字的 PR 来"美化"简历。其实面试官和我们猎头一眼就能看出来这是在刷 KPI。这把原本很纯粹的事情搞得太功利、太累了。

我认识的那些真正厉害的候选人，他们写代码最快乐的瞬间，其实和找工作无关。也许只是深夜偶然帮某个素未谋面的异国开发者修了一个 bug，或者随手写的小工具被人点了个 Star。在这个有些内卷的行业里，留一点纯粹的热爱给自己吧。带着乐趣去分享一行代码，比为了应付我们而堆砌出来的链接，要有生命力得多。

🎯 EMPATHY / 换位思考 2026.05.06

我收集的上百条面试反馈：比起聪明，面试官更看重你的"韧性"。

每天帮企业和候选人做面试复盘，我发现了一个很有意思的现象。在形形色色的候选人里，企业最终发 Offer 的，往往是同一类人……

很多学历背景耀眼、新技术名词倒背如流的聪明人，反而容易在终面折戟。而那些看起来有些笨拙，技术也许不是最拔尖，但在讲到自己是怎么苦熬三天排查一个线上内存泄漏问题时，眼里有光的人，却总能拿到满意的薪水。

因为大部分公司的日常开发是在打"逆风局"。顺风局谁都会写业务，但出了诡异的 Bug 时，拼的就是谁坐得住、谁有韧性。如果你在面试时，能自然流露出那种"这问题挺难搞，但我愿意死磕到底"的踏实劲儿，这比你在简历里写一百个"精通"，更能打动那些同样在一线摸爬滚打的面试官。

🤖 PRACTICE / 实践心得 2026.05.05

聊聊企业想要的 Agent 人才：少想点颠覆，多做点小工具。

很多企业给我提需求说要找"懂智能体协同的专家"，候选人也都在跟我聊这个。但深挖下去，其实大家都有点心虚……

市面上有很多关于"Agent 将颠覆公司架构"的讲座。但我从用人单位那边得到的真实反馈是：目前技术的稳定性还远远撑不起那么宏大的叙事，业务落地时动不动就死循环。

所以我常建议我的候选人：别去跟面试官空谈怎么造一个无所不能的 AI 系统。不如踏踏实实地用 API 写个小脚本，哪怕只是帮自己把每天整理日报的十分钟省下来，或者帮运营做个提炼摘要的小插件。少谈点颠覆时代的口号，多做点能立刻产生实际价值的微小工具。面试时拿这种自己写的小玩具出来演示，比空谈 PPT 概念讨喜得多，企业也更愿意为这种动手能力买单。

💰 CHOICE / 薪资取舍 2026.05.04

谈薪降薪：作为猎头，教你算一算心里的那个"隐形账本"。

大环境降温，很多候选人好不容易走到发 Offer 阶段，却发现薪资不及预期甚至降薪，陷入了深深的纠结。

帮候选人谈薪是我的日常。面对降薪，心里肯定难受，这是人之常情。但我通常会引导大家建一个"隐形账本"：这份新工作是不是能让你准时下班？团队的代码规范是不是健康、不用每天帮别人擦屁股？老板是不是个情绪稳定的讲理人？

有时候，表面工资数字的下降，换来的是周末不用随时待命的踏实，以及身心健康的极大提升。在这个求稳的阶段，平平安安地在一家靠谱的公司度过冬天，本身就是一种胜利。找工作要量力而行，不要总和社交平台上的"幸存者偏差"去比数字，自己过得舒坦、能学到东西，才是最实在的。

🤝 NETWORK / 人脉观念 2026.05.03

关于内推和"弱连接"：脸皮厚一点，我们猎头也很喜欢你主动找来。

很多内向的技术人，宁愿每天在招聘软件上盲投到深夜，也不好意思发个朋友圈问问机会，更别提主动找猎头了……

很多程序员可能觉得，找前同事内推或者是主动加猎头微信，是件拉不下脸的事情。但作为一个一线猎头，我想告诉你：在如今这海量简历的市场里，一个靠谱的内部推荐，能帮你跳过冰冷的机器筛选，省去巨大的内耗。

其实只要你平时做人踏实、干活不挖坑，大家是很乐意顺手帮你递个简历的。而且，主动把简历发给靠谱的猎头，告诉我们你的真实诉求，这绝对不是打扰。放下不必要的骄傲和社恐包袱，大方地推销自己的能力。学会利用身边的"弱连接"求助，本身也是职场成熟的标志之一。

🌧️ SURVIVAL / 面对裁员 2026.05.02

陪几百个候选人经历过裁员后，我想说：这不是你的错，只是一场天气变化。

最近行业里调整很多，身边有不少平时踏实肯干的老黄牛也被波及。看着他们在电话里自责，我心里也很唏嘘。

很多候选人被优化后跟我聊，第一句话总是觉得很失败，肯定是自己哪里没做好。我每次都会打断他们，特别认真地告诉他们：在这个时代，企业裁员往往跟个人的努力与否毫无关系。它更像是遇到了一场突如其来的暴雨，而你的业务线刚好被淋透了而已。

千万不要用公司的商业决策来惩罚自己的自尊心。收拾好东西，回去好好吃顿饭，睡一觉。天晴了，发个微信给我，带着你平时攒下的手艺和经验，换个地方接着干就是了。作为打工人，最大的底气，永远是我们手里这门真抓实干的手艺，而不是哪家公司的工牌。

🌸 PHILOSOPHY / 年度寄语 2026.05.01

写在 2026：做一个"悲观的乐观主义者"。

面对不确定的市场环境和日新月异的技术，看了那么多聚散离合的猎头，想给大家最后的一点小建议。

现在的环境，谁也不敢拍胸脯说未来一年会怎样。我身边的候选人，有的转行考公了，有的还在死磕技术。作为一个见证过周期起伏的猎头，我现在的状态大概算是一个"悲观的乐观主义者"。

悲观在于，我承认大环境没以前好了，大家不能再幻想轻松拿到几倍涨薪的 Offer；乐观在于，我相信哪怕技术再怎么变迁，那些真诚、靠谱、愿意脚踏实地帮团队解决问题的人，永远会有他的一席之地。少看点贩卖焦虑的新闻，多关心下自己的饭碗。每天干好手头的活，陪好身边的人。路还长，咱们慢慢走，总能找到一份踏实的回响。需要看机会的时候，记得随时找我聊聊。
